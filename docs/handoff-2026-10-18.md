`crates/opencat/src/bin/opencat-diff.rs`。k3diff 语义的 Rust 实现，替代
`tools/k3diff.py`（约束：禁止使用 Python）。逐帧流式解码 rgb24，输出
`mae` / `maxd` / `p2..p128` / bbox / grid 单元，并可直接 dump
`<frame>-ref.png`、`<frame>-test.png`、`<frame>-diff.png`（diff 是 8 倍增益热图）。

```sh
cargo build --release --bin opencat --bin opencat-diff
target/release/opencat render examples/hyperframes-launch/hyperframes-launch.jsx out/hyperframes-launch.mp4
target/release/opencat-diff.exe \
  "F:/hyperframes-launches/hyperframes-launch/renders/hyperframes-launch_2026-10-06_swgl.mp4" \
  out/hyperframes-launch.mp4 --out out/align-hf/diff3 --dump 140,164
```

## 已定位、未修复

### 1. 非换行文本强制左对齐（播放条时间文本错位的根因）

`crates/opencat-core/src/render/text.rs:363`：

```rust
let text_align = if item.allow_wrap {
    item.style.text_align
} else {
    TextAlign::Left
};
```

`#time` 有显式 `w-[110px] text-right`，但不允许换行，于是被强制左对齐。
参考帧 140 的时间文本贴右端，我们的紧跟在播放图标后面。修法：直接用
`item.style.text_align`；shrink-to-fit 的元素左右对齐本来就等价，不会回归。

同文件 `:89`、`:261` 的 `compute_line_x_shift` 已经是按 style 算的，不需要改。

### 2. backdrop-filter 只映射了 `blur`

`crates/opencat-core/src/css/to_node_style.rs:329` 的 `Property::BackdropFilter`
只处理 `Filter::Blur`，`saturate(1.12)` 等被丢弃。原版
`compositions/glass-intro.html` 的 `#frame` 是
`backdrop-filter: blur(14px) saturate(1.12)`。当前 JSX 只写 `backdrop-blur-[14px]`，
所以还不是本片的直接误差源，但补上才能和原版一致。接入点在
`render/dispatch.rs::save_composite_layer`：`ImageFilterSpec::Compose(css_filter, blur)`
已有，只需让 `backdrop_blur_sigma` 旁边多带一个 `CssFilter`。

### 3. 玻璃卡片环带 / 下巴偏灰

帧 140 采样：`960,950` 参考 `(72,123,158)`、我们 `(72,84,80)`；`960,860`
参考 `(79,74,67)`、我们 `(112,111,102)`。卡片四周边框区域参考透出饱和的彩色
背景，我们偏灰。原因候选：backdrop 两遍法（`engine/executor/replay.rs`）把
前缀 picture 用 `Clamp` 模糊后合成，和浏览器真实 backdrop 采样有差；也可能是
卡片自身 `linear-gradient(160deg, ...)` 的叠加顺序。

### 4. 背景视频相位

帧 92–115 全屏 `p8 ≈ 0.44`，但逐像素看两边构图一致，差异是整幅噪声纹理的
细微错位。素材 md5 与参考仓库一致（`bg.mp4`），YAVG 也接近（我们 220.7、
参考 219.6）。属于解码/采样相位问题，优先级低于 1、3。
